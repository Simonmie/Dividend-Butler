# 红利管家 Beta

版本：`0.1.0-beta.1`。桌面 VS Code / TRAE 扩展，用于本地记录 A 股红利 ETF 定投、查询公开行情与历史分红、估算下一次分红。

不连接券商、不自动交易、不上传本金或持仓。模拟成交不等于实际成交，历史预测不保证未来分红。

## 安装

1. 在 VS Code 或 TRAE 打开扩展面板。
2. 点击扩展面板右上角的 `…`，选择“从 VSIX 安装”。
3. 选择本项目 `releases/dividend-butler-0.1.0-beta.1.vsix`。
4. 按编辑器提示重新加载窗口。
5. 点击底部状态栏“红利 暂无估算”，或通过命令面板执行“红利管家：打开面板”。

要求桌面编辑器提供 VS Code `1.107.0` 或以上稳定 API。
VS Code 与 TRAE 的账本各自独立，不会自动同步，可用 JSON 备份迁移。

## 首次使用

1. 在“持仓”选择基金，填写初始份额、总投入成本和截至日期。
2. 截至日期表示当日收盘后的持仓快照。定投和手动买卖须晚于该日期。
3. 选择现金留存或模拟再投资，并填写再投资手续费规则。
4. 在“定投计划”配置每期金额、开始日期、周期、手续费。
5. 在“设置”阅读提示并开启公开数据查询，插件会获取行情与分红并补算已到期周期。
6. 返回“概览”查看持仓估算市值、预计分红和余款。

在线查询默认关闭。默认手续费为费率 `0.0003`、最低 `5` 元，仅是可修改的示例配置，不代表你的券商实际收费。

## 定投记账规则

- 支持每周、每月、每 N 个交易日；非交易日顺延。
- 每月日期不存在时取该月最后一天，再按交易日顺延。
- 金额包含手续费；费用支持固定费用，或费率加最低收费。
- 按最终可用的不复权日线收盘价，以 100 份整手买入，余款按计划独立结转。
- 预算不足一手时保留余款，不收取模拟成交手续费。
- 零成交量视为该 ETF 不可交易，等待下一可交易日。
- 缺日线时保留预算，暂停之后的账本补算；不会使用上一日价格冒充当日成交。
- 同一天顺延了多期计划时仍分别记录，各期 ID 不混淆。
- 编辑器关闭期间不运行；重开后按缓存和公开数据重放补算，不重复添加预算。
- “停止未来定投”保留截至当天的历史周期。修改或恢复请创建新计划，旧计划余款不会自动转入新计划。

“累计投入”包括初始总投入成本、定投预算及额外买入，并包含还未买入的预算余款；
它不是当前持仓成本，也不是市值或投资收益。

## 修正与手动交易

- 初始份额或成本填错，可在“持仓”修正；截至日期保持不变，之后账本会重算。
- 定投实际成交与模拟不同时，在“交易流水”点击“修正成交”填写实际份额、价格、费用。
- 未成交可填份额 `0`、手续费 `0`；价格仍需填写有效正数，但不会消耗预算。
- 缺行情的待补算记录也可通过实际成交信息解除阻塞。
- 定投之外的实际买入、卖出可单独补录；额外买入视为新增外部投入，卖出现金单独留存。
- 超出持仓的卖出、超出定投预算的修正会被拒绝，不落盘。
- 手动交易填错可删除后重录；生成交易的修正可“恢复模拟”。
- 重放采用日级顺序：手动交易、定投及再投资买入、登记日快照、当日派息，不还原盘中成交时序。

当前修正版本保存在账本中，上一有效账本另存本地备份；
本 Beta 暂不提供完整、可浏览的多版本交易审计历史。重要修正前建议主动导出备份。

## 分红与再投资

- 展示权益登记日、除息日、每份分红和发放日，自动将来源的“每 10 份”金额换算为每份。
- 默认状态栏合计每只 ETF 下一次可用预测，包含计划再投资，到账日期可能不同。
- 各基金分红方式独立设置；修改明日起生效，不改写过去已确认的事件。
- 现金留存和计划再投资在概览中分开显示，状态栏总额不是可支配现金余额。
- 已披露待发放事件优先使用披露数据；尚未公告时用历史间隔、每份分红中位数作透明估算。
- 历史不足、周期不稳定或预测已过期时显示暂无估算，不编造下次分红。
- 仅部分基金有可用预测时，状态栏标注“部分”，提示覆盖数量。
- 公开页面不是券商到账凭证，本 Beta 不自动核验基金公司实施公告。
- **未确认历史分红不会入账或触发再投资**。在分红日历中核对后确认，可填写实际到账金额；留空则按登记日份额模拟。
- 登记日早于初始快照或存在未完成补算时，不凭当前份额补写历史到账。
- 再投资在派息后下一交易日按收盘价模拟买入，计算手续费、整手与余款，不向券商下单。
- 份额折算事件会暂停补算，需核对当前份额并调整记录起点。

首期预测仅使用已有持仓；包含未来尚未执行定投的情景预测留待下一版本。

## 数据与隐私

- 行情：腾讯公开不复权日线；当前市值是最新可用收盘价估算，**不是实时盘中报价**。
- 历史分红：天天基金分红送配页面。
- 东方财富历史行情域名声明禁止自动访问，因此未接入该行情端点。
- 默认每 30 分钟检查行情缓存，分红成功缓存每日更新；支持手动刷新。
- 数据源失败保留上次成功数据并提示，解析失败不等于“没有分红”。
- 公开可访问不意味着开放 API 授权，第三方可变更、限流或延迟；本 Beta 不提供可用性保证，不用于数据商业再分发。
- 不绕过登录、验证码或封禁。接口停止可用时可关闭在线查询并手动录入分红。
- 用户账本放在 `ExtensionContext.globalStorageUri`，不写进你正在编辑的代码项目。
- 文件为本机明文 JSON；不默认加密、不加入设置同步，备份应妥善保管。
- 本地文件锁、修订版本校验与临时文件替换用于防止多窗口覆盖。
- 上一有效版本存为同目录 `ledger.backup.json`；损坏原文件在显式恢复时另存 `ledger.corrupt-*.json`。
- 面板有 CSP、消息校验和本地资源限制；不加载远端脚本或 CDN。

## 开发与测试

开发环境 Node.js 22.20 或兼容版本，依赖已锁定：

```sh
npm ci
npm run check
npm test
npm run build
npm run test:live
npm run test:host
npm run package
```

TRAE 隔离宿主测试（macOS）：

```sh
DIVIDEND_TEST_EDITOR="/Applications/Trae.app/Contents/MacOS/Electron" npm run test:host
```

源码调试可在构建后启动开发窗口：

```sh
code --extensionDevelopmentPath="/Users/jiangkexian/Desktop/红利管家"
```

`npm run preview` 启动 `http://127.0.0.1:4317` 的同款面板与真实应用服务，
使用临时账本，不会修改已安装扩展的数据；这里只用于 UI 验证，备份选择器必须在实际编辑器中测试。
